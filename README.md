# Admin Dashboard

A demo of admin dashboard UI built with HTML and CSS as a front-end development practice project. The design brings project cards, platform announcements, and trending repositories together in a clean, organized layout.

## Live Demo

[View Admin Dashboard](https://muhammad-aslam-khan.github.io/admin-dashboard/)

## Features

- **Project Overview:** Displays project cards with titles and short descriptions.
- **Announcements:** Highlights platform updates and important notices.
- **Trending Projects:** Showcases trending projects with usernames and brief descriptions.
- **CSS Grid Layout:** Organizes dashboard sections into a structured layout.
- **Reusable UI Components:** Uses consistent card-based sections for presenting information.
- **Clean Interface:** Focuses on readability, spacing, and visual organization.

## Built With

- HTML5
- CSS3
    - CSS Grid
    - Flexbox
    - CSS selectors and pseudo-classes
    - Responsive layout techniques

## Project Purpose

This project was created to practice front-end web development and explore how CSS Grid and Flexbox can be used to build a structured admin dashboard interface.

It also serves as a portfolio project demonstrating layout design, content organization, and styling with standard web technologies.
